# R U Socrates | Neural Interface Design Lab

> **Status**: Experimental UI/UX Playground for the [R U Socrates](https://github.com/zbbsdsb/R-U-Socrates) project.

This environment serves as the dedicated design staging ground for the **R U Socrates** Research OS. Our goal is to prototype high-performance, minimalist interfaces that facilitate collaborative AI research and hypothesis exploration.

## 🏛 Design Philosophy: Swiss Minimalist Neuralism

The interface is built upon the principles of the **Swiss Style** (International Typographic Style), adapted for modern AI-human collaboration:

- **Mathematical Grid**: Precise alignment and structural hierarchy.
- **High-Contrast Monochromatism**: Pure BLACK (`#000000`) background to reduce cognitive fatigue and emphasize data.
- **Neon Cyan Accents**: Used exclusively for active research flows and critical neural discoveries.
- **Typography as Interface**: Heavy reliance on *Inter* (Sans-serif) for clarity and *JetBrains Mono* for analytical transparency.

## 核心逻辑 / Core Modules

1. **Researcher Flow (Agent Topology)**: Real-time visualization of Agent collaboration (Researcher, Engineer, Analyzer).
2. **Thought Stream**: A terminal-inspired feed showing raw AI reasoning, Markdown-rendered hypotheses, and code snippets.
3. **Dialectic Comparison**: Side-by-side experimental views to compare different parameters or model syntheses.
4. **Sandbox Integrity**: Visual indicators for Docker-based execution environments and security enclaves.

## 快速开始 / Development

This project is a React-based SPA built with:
- **Vite** (Build Tool)
- **Tailwind CSS v4** (Styling)
- **Framer Motion** (Interaction Design)
- **Lucide React** (Iconography)
